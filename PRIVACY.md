## Privacy Policy

**Data Collection and Usage**

This plugin acts as a bridge between your Dify workspace and the third-party OpenAI-compatible API endpoint you configure in the provider credentials.

1. **Data Transmission**: Any text prompts, input images, and configuration settings you provide when using this tool are sent directly to the API endpoint you have specified (e.g., OpenAI, LiteLLM proxy, Vertex AI, or BytePlus).
2. **No Data Storage**: We (the plugin author, `abesticode`) do not intercept, store, log, or track any of your prompts, generated images, API keys, or personal data. All communication happens directly between your Dify environment and your configured API provider.
3. **Third-Party Policies**: How your data is handled after it is sent depends entirely on the Privacy Policy of the API provider you configured. We strongly recommend reviewing the privacy and data retention policies of your chosen API provider before using this plugin in production environments.

By using this plugin, you acknowledge and agree that your data will be transmitted to your configured API endpoints.
